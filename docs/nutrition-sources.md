# Справочник питания GlucoDay

## Что хранится в приложении

40 общих продуктов с русскими названиями и 10 простых рецептов. Это небольшой офлайн-справочник для приблизительного подсчёта порции, а не медицинская база, не каталог российских торговых марок и не индивидуальный план питания. Углеводы округлены до 0,1 г, энергия — до целых ккал на 100 г съедобной части. Значения относятся только к состоянию, указанному в названии: сухая крупа, варёная крупа, запечённое мясо, очищенное яйцо и т. п.

База — общие продукты USDA Standard Reference / FoodData Central. Английское название записи и ссылка на поиск первоисточника сохранены для каждого продукта в `nutrition/Nutrition.kt` и доступны из карточки. Поиск USDA может показывать несколько редакций справочной записи; это не обещание совпадения с анализом конкретного продукта. Например, цельнозерновой хлеб, сыр, йогурт и зернёный творог заметно различаются по составу между производителями. Пользователь может перенести данные своей упаковки в «Свой продукт».

USDA `Carbohydrate, by difference` включает пищевые волокна. Это не «чистые» или автоматически доступные углеводы; показатель может отличаться от строки «углеводы» российской этикетки. Приложение показывает это пояснение рядом с расчётом и не выполняет скрытое вычитание клетчатки. Все расчёты сохраняют выбранную пользователем основу.

## Первичные источники

Ссылки проверялись 8 октября 2026 года. Встроенный каталог не обновляется по сети автоматически.

- [USDA FoodData Central](https://fdc.nal.usda.gov/) — официальный каталог и поиск общих продуктов. Данные USDA находятся в общественном достоянии.
- [Документация FoodData Central](https://fdc.nal.usda.gov/data-documentation/) — типы данных и ссылки на Standard Reference / Foundation Foods.
- [Документация Foundation Foods, апрель 2024](https://fdc.nal.usda.gov/docs/Foundation_Foods_Documentation_Apr2024.pdf) — определения энергии и углеводов; пересчёт из значений на 100 г.
- [USDA Standard Reference 27: крупы и макароны](https://www.ars.usda.gov/ARSUserFiles/80400525/Data/SR27/reports/sr27fg20.pdf) — гречка, рис и паста, отдельные сырые/готовые записи.
- [USDA Standard Reference 28: хлопья и каши](https://www.ars.usda.gov/ARSUserFiles/80400535/Data/SR/SR28/reports/sr28fg08.pdf) — например, NDB 08120, овсяные хлопья: 67,70 г углеводов, 379 ккал на 100 г сухого продукта.
- [USDA Standard Reference 28: овощи](https://www.ars.usda.gov/ARSUserFiles/80400535/Data/SR/SR28/reports/sr28fg11.pdf) — сырые и приготовленные овощи.
- [USDA Standard Reference 27: фрукты](https://www.ars.usda.gov/SP2UserFiles/Place/80400525/Data/SR27/reports/sr27fg09.pdf) — например, NDB 09003, яблоки с кожурой.
- [USDA Standard Reference 27: молочные продукты и яйца](https://www.ars.usda.gov/ARSUserFiles/80400525/Data/SR27/reports/sr27fg01.pdf) — например, NDB 01015, зернёный творог 2%, а не обычный российский творог.
- [USDA Composition of Foods: cheddar, NDB 01009](https://www.govinfo.gov/content/pkg/GOVPUB-A-PURL-gpo17007/pdf/GOVPUB-A-PURL-gpo17007.pdf) — историческая общая запись 403 ккал / 1,28 г углеводов на 100 г, округлённая в приложении.

## Расчёты

Для продукта: `значение на 100 г × масса в граммах / 100`.

Для рецепта: сумма значений всех ингредиентов, затем умножение на `выбранные порции / базовые порции`. Промежуточные результаты не округляются. Экран округляет показания до одного десятичного знака, а дневник получает исходный результат расчёта.

Пример: овсянка из 40 г сухих хлопьев, 150 г молока 2% и 80 г яблока даёт по встроенным исходным данным 45,32 г общих углеводов и 268,2 ккал. Половина указанной порции: 22,66 г и 134,1 ккал. Это арифметическая оценка, не лабораторный анализ.

Рецепты используют указанные массы ингредиентов; приложение не выводит неизвестный конечный вес после варки и не подменяет сухую массу готовой. Масса воды, впитывание/испарение и кулинарные потери не моделируются. Масло, соусы, замены и другие добавки требуют отдельного учёта. Время большинства рецептов — сборка из готовых ингредиентов. Нет обещаний «подходит при диабете», лечебных диет, расчётов доз или «разрешённых/запрещённых» продуктов.

## Локальные пользовательские данные

Отдельный `SharedPreferences` с именем `glucoday_nutrition` хранит список пользовательских продуктов (`id`, `name`, `carbs`, `kcal`) и идентификаторы избранного. Пользовательские значения помечены «Введено вами по этикетке» и не выдаются за проверенные USDA. Ввод поддерживает десятичную запятую, отклоняет NaN, бесконечность, отрицательные значения, экспоненциальную запись и неоднозначные разделители.

Этот небольшой каталог и избранное не входят в JSON-резервную копию дневника. В дневник через callback поступают название приёма пищи, рассчитанные углеводы и ккал. Запросов к ИИ, анализа медицинских сведений, фотографий еды и отправки данных на внешние серверы нет. Внешние ссылки USDA открываются только по нажатию пользователя.

## Проверки

`NutritionTest` проверяет дробную массу, запятую/точку, граничные значения, нулевые углеводы с этикетки, суммы ингредиентов, половину/двойную порцию, рецепты на несколько порций, целостность идентификаторов, отсутствие неизвестных ингредиентов и отказ при нечисловых/отрицательных величинах.
