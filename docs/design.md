# Интерфейс

GlucoDay использует спокойную зелёную палитру и нативные компоненты Material 3. Тёмная тема — стартовая; доступны светлая и системная.

- Сетка на базе 4/8 dp, основные межблочные интервалы 16 dp и поля 20 dp.
- Пять разделов: сегодня, дневник, еда, шаги и профиль.
- Быстрый ввод глюкозы — главное действие первого экрана и отдельный виджет.
- Интерактивные элементы не меньше 48 dp. Формы прокручиваются при открытой клавиатуре.
- Системные области, вырез камеры и навигация учитываются через safeDrawing. Для стороннего «острова» предусмотрен дополнительный верхний отступ.
- Состояния без данных не заменяются демоданными, нулями или вымышленным прогрессом.
- График глюкозы показывает отдельные измерения без линии, предполагающей непрерывное наблюдение.
- Данные доступны текстом; смысл не передаётся только цветом.

Знак приложения — капля с компактным символом добавления. Adaptive icon поддерживает системную форму и монохромное оформление Android.
