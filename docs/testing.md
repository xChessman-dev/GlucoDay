Проверено 8 октября 2026 года.

- `testDebugUnitTest`: 38 проверок, 0 ошибок. Валидация ввода, единицы сахара, сохранение точности при редактировании, JSON/CSV, расчёты питания, локальные даты и переходы часового пояса.
- Android 15 / API 35, эмулятор 1080×2400: 9 инструментальных проверок, 0 ошибок. Из них 3 сценария Compose и 6 проверок Room, включая повторное открытие базы, идемпотентные отметки лекарств, импорт и фактический откат частичной транзакции.
- `assembleRelease` и `lintRelease`: успешно, без ошибок Lint. Предупреждения об обновлениях зависимостей и стиле кода не скрыты baseline-файлом.
- Подпись release APK проверена `apksigner` (APK Signature Scheme v2).
- Визуально проверены основные экраны и масштаб шрифта 130%.

Тестовые значения не включены в приложение. UI-тесты запускаются только на эмуляторе и удаляют только созданные ими записи; тесты репозитория используют отдельную базу.

## Что проверить на реальном телефоне

1. Добавить показание, закрыть приложение и убедиться, что запись сохранена.
2. Разрешить Health Connect чтение шагов; проверить наличие источника данных и совпадение количества с ним.
3. Добавить напоминание и проверить его при выключенном экране с текущими настройками энергосбережения.
4. Открыть клавиатуру и пройти формы с используемым «островом» камеры; при необходимости увеличить верхний отступ в профиле.
5. Сохранить JSON-копию в безопасное место и проверить её восстановление.

Эмулятор не подтверждает работу датчиков конкретного телефона, OEM-ограничения уведомлений или совместимость с конкретной сторонней накладкой над камерой. Эти проверки остаются для устройства.
