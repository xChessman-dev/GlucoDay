# GlucoDay

Личный дневник глюкозы, питания и повседневных привычек для Android. Русский интерфейс, локальное хранение, работа без регистрации и облачного аккаунта.

**Статус: personal beta 0.1.0.** Приложение помогает вести собственные записи. Оно не ставит диагноз, не определяет целевые показатели и не рассчитывает дозы лекарств или инсулина.

## Возможности

- Глюкоза: значение, время, контекст измерения и заметка; отображение в ммоль/л или мг/дл.
- Питание: дневник приёмов пищи, углеводы и калории, расчёт порций в граммах или порциях рецепта.
- Офлайн-справочник: 40 продуктов и 10 рецептов, поиск, избранное и свои продукты по этикетке.
- Вес: записи с датой и историей изменений.
- Лекарства: пользовательское расписание, текст дозировки, отметки приёма за день и локальные уведомления.
- Шаги: чтение доступных данных за семь дней из Health Connect с явным состоянием доступа и последнего обновления.
- Профиль: необязательные личные сведения, свои целевые границы глюкозы, цель шагов, тема и дополнительный верхний отступ экрана.
- JSON-копии для переноса дневника и CSV для просмотра записей в таблице.
- Виджет, открывающий быстрое добавление измерения.

При первом запуске дневник пуст. Приложение не создаёт демонстрационные измерения, не подставляет медицинские цели и не считает отсутствие данных Health Connect нулём шагов.

## Что следует учитывать

**Шаги.** Дневник работает на Android 8 и новее. Раздел шагов требует совместимого Health Connect, разрешения на чтение и источника, который передаёт туда шаги. Поддержка и наличие записей зависят от телефона, версии системы и подключённых приложений или часов. GlucoDay читает шаги при открытии или обновлении раздела; непрерывного фонового трекинга и геолокации нет.

**Напоминания.** Уведомления используют приблизительное время Android. Энергосбережение, ограничения фоновой работы и настройки производителя могут задержать их. После принудительной остановки приложения откройте его снова. Отметка приёма — запись пользователя, она не подтверждает фактический приём лекарства. Удаление расписания также удаляет его историю отметок.

**Питание.** Значения в справочнике ориентировочные: отличаются состав, бренд, приготовление и масса готового блюда. Для конкретного продукта проверяйте этикетку. Рецепты рассчитываются суммированием ингредиентов. В справочных данных USDA показатель total carbohydrate включает пищевые волокна; его нельзя без поправок считать эквивалентом любой локальной маркировки. Источники открываются во внешнем браузере по нажатию.

**Проверка ввода.** Поддерживаются точка и запятая в десятичном числе. Некорректные, отрицательные и нечисловые значения, а также будущие даты записей отклоняются с объяснением. Технически принимаемый диапазон глюкозы — 0,1–60 ммоль/л; это ограничение ввода, а не медицинский целевой диапазон. В базе значение хранится в ммоль/л без округления для отображения.

## Резервные копии

JSON включает профиль, измерения глюкозы, приёмы пищи, вес, расписания лекарств и историю отметок. Копия содержит исходные числовые значения, идентификаторы и время записей. Для отметок лекарства сохраняется также календарный день, чтобы история не менялась при смене часового пояса.

Перед импортом проверяются формат, версия, поля, диапазоны, связи и повторяющиеся идентификаторы. Лимиты — 10 МиБ и 50 000 записей. Импорт выполняется одной транзакцией: новые записи добавляются, записи с совпадающим UUID обновляются. Остальной дневник сохраняется. Замена профиля выбирается отдельно и по умолчанию выключена. Конфликт разных отметок одного лекарства за один день отменяет импорт. Ошибка не оставляет частично восстановленные данные.

Свои продукты и избранное справочника, системные разрешения, служебные настройки уведомлений и данные шагов Health Connect **не входят** в JSON-копию. Сохранённые приёмы пищи входят в неё независимо от использованного продукта. CSV содержит записи дневника и лекарств; это формат для просмотра, а не восстановления. Он использует UTF-8 и экранирует текст, который табличные редакторы могли бы интерпретировать как формулу.

JSON и CSV не зашифрованы. Выбирайте безопасное место сохранения и проверяйте получателей перед передачей файлов. Выбор облачного хранилища в системном диалоге передаёт файл выбранному провайдеру. Подробнее: [конфиденциальность](docs/privacy.md).

## Сборка

Требуются JDK 17, Android SDK Platform 36 и Android SDK Build Tools. Gradle Wrapper использует Gradle 8.13; Android Gradle Plugin — 8.13.2, Kotlin — 2.2.21. Минимальная версия Android — API 26, целевая — API 36.

1. Откройте каталог проекта в Android Studio или настройте `JAVA_HOME` и `ANDROID_HOME`.
2. При необходимости создайте локальный `local.properties` с параметром `sdk.dir`, указывающим на ваш Android SDK. Этот файл не публикуется.
3. Соберите приложение и запустите проверки:

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

На macOS и Linux используйте `./gradlew` с теми же задачами. Первая сборка скачивает зависимости разработки; установленному приложению они не требуются.

Debug APK создаётся в `app/build/outputs/apk/debug/`. Для проверки Room, восстановления и сохранения после повторного открытия базы подключите Android-устройство или запустите эмулятор:

```powershell
.\gradlew.bat connectedDebugAndroidTest
```

Для release-сборки поддерживается локальный `keystore.properties` с полями `storeFile`, `storePassword`, `keyAlias` и `keyPassword`. Ключи подписи и пароли не должны попадать в репозиторий. Обновление установленного приложения требует той же подписи.

## Устройство проекта

| Каталог | Назначение |
| --- | --- |
| `app/src/main/java/dev/chessman/glucoday/domain` | Модели, проверки ввода, даты, преобразование единиц, CSV |
| `app/src/main/java/dev/chessman/glucoday/data` | Room, наблюдаемый снимок данных, JSON-копии и атомарный импорт |
| `app/src/main/java/dev/chessman/glucoday/nutrition` | Офлайн-продукты, рецепты, порции и локальный пользовательский справочник |
| `app/src/main/java/dev/chessman/glucoday/platform` | Health Connect, уведомления и виджет |
| `app/src/main/java/dev/chessman/glucoday/ui` | Интерфейс Jetpack Compose |
| `app/src/test` | Проверки доменной логики, форматов и расчётов |
| `app/src/androidTest` | Проверки Android и репозитория на устройстве |

В приложении нет аналитики, рекламных SDK, собственного сервера, API-ключей или разрешения `INTERNET`. База находится в закрытом каталоге приложения. Автоматическое резервное копирование Android отключено; для переноса дневника предусмотрен явный экспорт.
